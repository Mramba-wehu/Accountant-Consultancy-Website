# Mwanje & Associates - Website

Welcome to the source code for the Mwanje & Associates website!

## About
Mwanje & Associates is a leading Certified Public Accountants (Kenya) firm in Mombasa providing expert outsourced accounting, tax services, payroll processing, and business advisory for growing enterprises.

Led by **CPA. Mwanyamba Douglas Mwanje** (Managing Partner), we are committed to delivering top-tier financial solutions that empower businesses in Kenya to thrive.

## Features
- **Full-Stack Architecture:** Powered by a Node.js backend serving dynamic frontend content.
- **Admin Portal & CMS:** Secure admin dashboard to modify website content, protected by Email-based Two-Factor Authentication (2FA).
- **Advanced SEO:** Fully optimized for search engines utilizing JSON-LD Schema.org Structured Data (Local Business), XML Sitemaps, and robots.txt.
- **Mobile-First Responsive Design:** Ensures a seamless experience across desktop, tablet, and mobile devices with interactive hamburger navigation.
- **Accessibility:** Built-in accessibility options including dark/light mode toggle, high contrast mode, and adjustable font sizes.
- **Modern UI:** Vibrant, professional look focusing on user engagement and conversion.

## Technologies Used
**Frontend:**
- HTML5
- CSS3 (Mobile-First custom responsive styling)
- Vanilla JavaScript
- Font Awesome (Icons)
- Google Fonts (Outfit & Plus Jakarta Sans)

**Backend:**
- Node.js
- Express.js (Web Server & API routing)
- Nodemailer (Email service for 2FA delivery)
- express-session (Secure authentication state)

## Getting Started Locally
To run this project on your local machine:
1. Clone the repository.
2. Run `npm install` to download backend dependencies.
3. Run `npm start` or `node server.js` to start the local server.
4. Open `http://localhost:3000` in your web browser.
5. To access the admin panel, navigate to `http://localhost:3000/admin.html`.
